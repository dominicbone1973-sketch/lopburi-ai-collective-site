# Lopburi AI Collective — public website

Public preview hosted with GitHub Pages. The static website lives at the repository root: index.html, CSS/JavaScript and assets/. GitHub Pages publishes main from / (root). The .nojekyll file preserves the static assets without a Jekyll build.

This is an exported publication copy. The separate development repository remains private. Changes are developed locally and published deliberately, not automatically from every development commit.

The approved hero media is preserved. Nori is a local bilingual FAQ prototype. Email/LINE routes are available, but form drafts require the visitor to send an email; automatic subscriptions, bookings and live AI are not active. Event details remain provisional.

Private contact registers, email records, diary content and development history are excluded. The public site-status page replaces the earlier internal proposal page. No blanket open-source licence is granted; font licence notices are retained in assets/.
